# 🎱 Magic 8-Ball 3D

An interactive, responsive web application inspired by the classic Magic 8-Ball fortune-telling toy, upgraded with a realistic 3D rendered billiard ball, mouse-tracking parallax, witty answers, and procedural sound effects.

Klasik Magic 8-Ball kehanet oyuncağından esinlenerek geliştirilmiş; gerçekçi 3D küre render'ı, fareyi takip eden 3D paralaks eğimi, esprili Türkçe yanıt havuzu ve tarayıcı tabanlı ses efektleriyle zenginleştirilmiş interaktif web uygulaması.

## ✨ Features / Özellikler

### 🇬🇧 English
* **3D Rendered Sphere:** Realistic billiard 8-ball appearance crafted with dynamic multi-stop radial gradients, specular highlight sheen, and contact drop shadow.
* **Interactive Mouse Parallax (3D Tilt):** The 8-ball tilts and rotates in real-time 3D perspective following your mouse cursor, dynamically adjusting specular reflection.
* **Witty & Humorous Turkish Fortune Pool:** Over 40+ humorous, sarcastic, positive, and classic fortune-telling responses with color-coded ambient moods.
* **Procedural Sound Engine:** Native Web Audio API sound synthesis (rattling shake sound and mystic chime on reveal) with zero external audio assets.
* **Modern Glassmorphic UI:** Deep space dark theme, quick question chips, smooth 3D shake animation, and mobile-friendly responsive layout.
* **Keyboard & Accessibility Support:** Press `Enter` to ask, keyboard navigation support, and instant reset button.

### 🇹🇷 Türkçe
* **3D Render Edilmiş Küre:** Çok katmanlı radyal gradyanlar, yüzey parlaması ve zemin temas gölgesi ile gerçekçi 3D bilardo topu görünümü.
* **Fareyi Takip Eden 3D Paralaks (Tilt):** Top, farenin hareketine göre gerçek zamanlı 3D perspektifte eğilir; yüzeydeki ışık yansıması fare yönüne göre fiziksel olarak kayar.
* **40+ Esprili & Özgün Türkçe Yanıt:** Klasik yanıtların yanı sıra kahkaha attıran, iğneleyici ve eğlenceli kehanet havuzu ve tematik renk geçişleri.
* **Prosedürel Ses Motoru (Web Audio API):** Harici ses dosyası indirmeden çalışan saf Web Audio API sallama ve kristal çınlama efektleri (isteğe bağlı ses kapatma anahtarı).
* **Modern Glassmorphism Arayüzü:** Derin uzay teması, hazır hızlı soru çipleri, şiddetli 3D sallanma efekti ve mobil uyumlu tasarım.
* **Klavye & Erişilebilirlik Desteği:** `Enter` tuşuyla doğrudan soru sorma, tek tıkla sıfırlama ve erişilebilir form kontrolleri.

## 🚀 How to Run Locally / Yerelde Çalıştırma

Projeyi çalıştırmak için herhangi bir paket yöneticisi veya derleyiciye ihtiyaç yoktur:

1. Repoyu klonlayın:
   ```bash
   git clone https://github.com/byKAYRA/Magic-8-Ball.git
   ```
2. Klasöre gidin:
   ```bash
   cd Magic-8-Ball
   ```
3. `index.html` dosyasını favori tarayıcınızda çift tıklayarak veya bir yerel sunucuyla açın:
   ```bash
   # Python ile yerel sunucu (isteğe bağlı):
   python -m http.server 8000
   ```
