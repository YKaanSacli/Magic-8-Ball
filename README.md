# 🎱 Magic 8-Ball

An interactive, responsive web application inspired by the classic Magic 8-Ball fortune-telling toy.

Klasik Magic 8-Ball kehanet oyuncağından esinlenerek geliştirilmiş, kullanıcıların sorularına rastgele yanıtlar veren interaktif web uygulaması.

---

Projeyi tarayıcınızda doğrudan deneyimleyebilirsiniz:  
👉 **[Magic 8-Ball Oyunu Oyna](https://ykaansacli.github.io/Magic-8-Ball/)**

---

## 📌 Features / Özellikler

* **EN:**
  * Clean, responsive user interface designed with pure HTML, CSS, and JavaScript.
  * Generates instant random answers to yes/no questions.
  * Hosted live via GitHub Pages.
* **TR:**
  * Saf HTML, CSS ve JavaScript ile hazırlanmış sade ve mobil uyumlu arayüz.
  * Evet/Hayır sorularına anlık rastgele yanıtlar üretme.
  * GitHub Pages üzerinden canlı yayın desteği.

---

## 🛠️ Built With / Kullanılan Teknolojiler

* **HTML5** - Page structure / Sayfa yapısı
* **CSS3** - Styling & animations / Stil ve animasyonlar
* **JavaScript (Vanilla)** - Game logic / Oyun mantığı
